# Data Model: Magpie Rebrand

No stored data changes. No SQLite schema change, no new `setting` key. The entities below are configuration and files.

## App Identity

| Field | Value | Where it lives |
|-------|-------|----------------|
| Display name | `Magpie` | `app.config.ts` `name` |
| Reminder title | `Magpie` | `src/strings.ts` `reminderTitle` |
| Notice text | "Magpie is not made by or linked with YouTube or Google. YouTube is a trademark of Google LLC." | `src/strings.ts` `notAffiliated` |
| Brand background | `#1F1F1F` | icon background layer, iOS icon, opening screen |
| Brand mark color | `#F3F3E7` | art in the master icon |

Rules: the display name and reminder title are the same word. The notice is two sentences, each with one idea.

## Project Identifiers

| Field | Old | New | File |
|-------|-----|-----|------|
| Project name | `youtube-subs-migrator` | `magpie` | `package.json`, `package-lock.json` |
| Install link name (slug) | `youtube-subs-migrator` | `magpie` | `app.config.ts` |
| Android package | `com.dodotechhub.subsmigrator` | `com.dodotechhub.magpie` | `app.config.ts` |
| iOS bundle | `com.dodotechhub.subsmigrator` | `com.dodotechhub.magpie` | `app.config.ts` |

Rules: all four use the same word. None contains "youtube" (FR-009). A change of Android package or iOS bundle makes a different app for the phone and the stores, so it is final once released.

## Icon Set (generated by `scripts/make-icons.sh` from `assets/magpie-icon-master.png`)

| File | Size | Content | Used for |
|------|------|---------|----------|
| `assets/icon.png` | 1024 x 1024 RGB | Master on `#1F1F1F`, no alpha | iOS icon, fallback |
| `assets/android-icon-background.png` | 432 x 432 | Flat `#1F1F1F` | Android adaptive background |
| `assets/android-icon-foreground.png` | 432 x 432 RGBA | Art only, scaled to fit the 66 dp safe circle | Android adaptive foreground |
| `assets/android-icon-monochrome.png` | 432 x 432 RGBA | Same shape, one flat color | Android 13+ themed icon |
| `assets/splash-icon.png` | 1024 x 1024 RGBA | Art only, transparent around it | Opening screen |
| `assets/notification-icon.png` | 96 x 96 RGBA | White mark on transparent | Android notification small icon |
| `assets/favicon.png` | 48 x 48 | Downscale of `icon.png` | Web fallback |

Rules: no file contains a mark that is not part of the logo (FR-006). iOS icon has no transparency (FR-005). Every Android art pixel sits inside the safe circle (FR-004).

## Google Sign-In Credentials (outside the repo)

| Item | Needs |
|------|-------|
| Android OAuth client | Package `com.dodotechhub.magpie` and the signing SHA-1 |
| iOS OAuth client | Bundle `com.dodotechhub.magpie`; its ID feeds `EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID` |
| Consent screen | App name "Magpie", the new icon, support email, privacy policy link |

Rules: public IDs only, never a secret in the repo (constitution III.4).
